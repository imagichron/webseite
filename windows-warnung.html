Windows warnt beim Installieren?

Beim ersten Start des Setups zeigt Windows manchmal eine blaue Warnung. Das liegt nicht an einem Fehler im Programm: Imagiter ist neu, und das Setup ist (noch) nicht mit einem kostenpflichtigen Zertifikat signiert. Windows kennt es deshalb noch nicht und fragt sicherheitshalber nach.

Weitere Informationen

Nicht ausführen

  1. Klicke in der blauen Meldung auf „Weitere Informationen“.
  2. Prüfe, dass dort als App Imagiter-Setup steht.
  3. Klicke auf „Trotzdem ausführen“. Das Setup startet.

Warnt schon der Browser beim Herunterladen (z. B. Edge: „wird nicht häufig heruntergeladen“), klicke auf die drei Punkte neben der Datei → „Beibehalten“.

Geht gar nicht? Intelligente App-Steuerung

Ist auf deinem PC die „Intelligente App-Steuerung“ eingeschaltet (Windows 11, Windows-Sicherheit → App- und Browsersteuerung), blockiert Windows unsignierte Programme ganz, ohne „Trotzdem ausführen“. Bitte schalte sie dafür nicht aus. Eine signierte Fassung über den Microsoft Store ist in Vorbereitung; bis dahin schreib uns gern an kontakt@imagiter.de.

Ist die Datei echt?

Lade Imagiter nur von imagiter.de herunter. Wer ganz sicher gehen will, vergleicht die Prüfsumme: Sie steht im Download-Bereich. In der PowerShell (Startmenü → „PowerShell“) zeigt dieser Befehl die Prüfsumme der heruntergeladenen Datei:

Get-FileHash "$env:USERPROFILE\Downloads\Imagiter-Setup-*.exe"

Stimmen beide Zeichenfolgen überein, ist die Datei unverändert.
